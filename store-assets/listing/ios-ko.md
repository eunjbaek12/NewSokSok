### ⑬ 이름 길이의 희석 효과 — 상위 10위 구간에만 있다 (8/23 저녁 실측)

🔑 **검사법** — 한글(또는 그 언어) + ASCII 만 남았는지 코드포인트로 센다. 눈으로는 안 걸린다

```python
import unicodedata
for ch in text:
    if ord(ch) > 0x7f and not (0xAC00 <= ord(ch) <= 0xD7A3):
        print(hex(ord(ch)), unicodedata.name(ch, '?'), ch)
```

⚠️ **거부 사유 문구 자체는 기록하지 못했다.** 다음에 걸리면 메시지 원문을 남길 것 —
