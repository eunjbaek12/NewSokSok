## 4편 풀스크립트

공통: 각 편 인트로 마스코트 → 기능 "와" 순간(화면 녹화) → 끝 카드. `[화면 녹화]` 표시 구간만 실제 앱 캡처.

### 1편 — AI 자동완성 "채워줄게" (~20s)
| 컷 | 시간 | 화면 | 화면 자막 | 음악/전환 |
|---|---|---|---|---|
| 1 | 0–2s | 아보카도 통통 등장, 빈 단어 카드 배경 | "단어 뜻·예문, 아직도 다 검색해? 🥑" | 비트 인 + 팝 |
| 2 | 2–5s | [화면 녹화] add-word 검색창에 `ephemeral` 타이핑 | "단어 하나만 쳐봐" | 타건음 |
| 3 | 5–7s | 아보카도가 단어를 한입 꿀꺽 → 반짝 카드 뱉음 | "내가 채워줄게 ✨" | 꿀꺽 효과음 |
| 4 | 7–13s | [화면 녹화] 뜻·예문·발음·품사 자동 채워짐 | "뜻·예문·발음 한 번에" | 비트 드롭 + 휙 |
| 5 | 13–16s | 완성된 단어 카드 클로즈업 | "검색 0번. 끝." | 딩 |
| 6 | 16–20s | 아보카도 + 끝 카드 | "아보카도 · 단어장 학습 — 곧 출시 🥑" | 아웃트로 |

### 2편 — 사진 "찍어서 만들어줄게" (~20s)
| 컷 | 시간 | 화면 | 화면 자막 | 음악/전환 |
|---|---|---|---|---|
| 1 | 0–2s | 아보카도가 영어 교재 페이지 옆 등장 | "이 페이지, 통째로 단어장 만들어줄게 📸" | 비트 인 |
| 2 | 2–5s | [화면 녹화] 카메라 뷰로 영어 지문/단어목록 비춤 | "타이핑 귀찮지?" | — |
| 3 | 5–7s | 아보카도가 셔터 누름 → 화이트 플래시 | "찍기만 해" | 셔터음 |
| 4 | 7–13s | 종이에서 단어 빨려나옴 + [화면 녹화] 추출 리스트 | "단어들이 쏙쏙 추출" | 흡입 + 드롭 |
| 5 | 13–16s | [화면 녹화] 완성된 단어장 | "단어장 완성 ✅" | 딩 |
| 6 | 16–20s | 끝 카드 | "아보카도 · 단어장 학습 — 곧 출시 🥑" | 아웃트로 |

### 3편 — 단어 자동생성 "만들어줄게" (~20s)
| 컷 | 시간 | 화면 | 화면 자막 | 음악/전환 |
|---|---|---|---|---|
| 1 | 0–2s | 아보카도가 빈 단어장 앞에서 갸웃, 물음표 | "외울 단어가 없다고? ✈️" | 비트 인 |
| 2 | 2–5s | [화면 녹화] 주제 입력 "여행 영어 20개" | "주제만 말해" | 타건음 |
| 3 | 5–7s | 아보카도가 모자/냄비에서 단어 꺼내는 마술 | "내가 만들어줄게" | 마법 사운드 |
| 4 | 7–13s | [화면 녹화] 20개 단어 세트 좌르륵 생성 | "20개 뚝딱" | 드롭 + 촤르륵 |
| 5 | 13–16s | 주제 3개 빠른 컷(시험/관심사/여행) | "시험도, 관심사도, 여행도" | 컷 비트 3회 |
| 6 | 16–20s | 끝 카드 | "아보카도 · 단어장 학습 — 곧 출시 🥑" | 아웃트로 |

### 4편 — 학습 "외우게 해줄게" (~22s)
| 컷 | 시간 | 화면 | 화면 자막 | 음악/전환 |
|---|---|---|---|---|
| 1 | 0–2s | 아보카도가 단어 카드 더미 위에, 별 반짝 | "외우는 게 이렇게 쏙쏙 될 일이야? 🥑" | 비트 인 |
| 2 | 2–6s | [화면 녹화] 카드 뒤집기 + 좌/우 스와이프(다시/외움) | "넘기면서 외우는 카드" | 스와이프 휙휙 |
| 3 | 6–9s | [화면 녹화] 퀴즈 정답 | "퀴즈로 점검" | 정답 딩 |
| 4 | 9–12s | [화면 녹화] 예문 + 자동재생 섀도잉 | "예문·섀도잉까지" | — |
| 5 | 12–16s | 외운 단어에 아보카도 도장 쾅쾅 | "골라서 쏙쏙" | 도장 쾅 + 드롭 |
| 6 | 16–22s | 끝 카드 | "아보카도 · 단어장 학습 — 곧 출시 🥑" | 아웃트로 |

## 제작 실행 런북 (Phase A~E — 보면서 그대로 실행)

> Veo는 영상 "엔진", Gemini 앱은 그 엔진을 쓰는 창구. Gemini에서 영상 생성 = Veo 사용. 세밀 제어가 필요하면 같은 AI Pro에 포함된 **Flow**(labs.google/flow)로 이동.
>
> **역할 분담(절대 원칙)**: 마스코트 컷 = **Gemini(Veo) 생성** / 앱 기능 화면 = **실제 화면 녹화**(Veo는 가짜 UI를 지어냄) / 자막·글자·조립 = **CapCut**(Veo는 글자를 깨뜨림)

**생산 순서**: **1편(자동완성)을 먼저** 만들어 워크플로우 검증 → 나머지. (공개 순서 2→1→3→4와는 별개)

```
[A] 공통 자산(1회) → [B] 화면 녹화(몰아찍기) → [C] 마스코트 컷(Veo, 1컷검증→확장) → [D] CapCut 조립(편당) → [E] QA→보관
```

### Phase A — 공통 자산 준비 (한 번만, 4편 공유)
4편이 같은 옷을 입어야 시리즈로 인식됨.

- [ ] **A1. 캐릭터 기준 이미지** (Gemini 이미지 생성) — `assets/images/icon.png` 첨부 + 프롬프트:
  > 첨부한 아보카도 캐릭터와 똑같은 3D 렌더 스타일·색·표정으로, 책상·책·램프 등 소품 전부 제거하고 캐릭터만. 정면, 전신, 자연스럽게 서 있는 포즈(잎 손 보이게), 부드러운 스튜디오 조명, 단색 연한 배경. 깨끗한 캐릭터 컷.

  → 깨끗한 1장 저장. **같은 세션에서 포즈 3종 더**(손 흔드는·카드 든·엄지 척) 확보 = 끝카드 + 일관성에 결정적
- [ ] **A2. 공통 스타일 토큰 고정** (전 컷 동일): warm cream 배경 + 틸 `#2A7B78` · 9:16 세로 · 편당 15~22초 · 자막 항상 · **음악 단일 트랙 1곡**(CapCut 상업적 사용 가능 라이브러리, 라이선스 확인) · 폰트 1종(앱과 동일 **Pretendard** 계열 권장) · 인트로 0~2s 동일 패턴
- [ ] **A3. 끝 카드 1종**(전편 동일): `아보카도 · 단어장 학습 — 곧 출시 🥑`. 마스코트 포즈컷(A1) + 글자는 **CapCut**. (출시일엔 "곧 출시"→"출시 완료 🥑" 변형 1종 추가)

### Phase B — 화면 녹화 (`[화면 녹화]` 구간, 1세션 몰아찍기)
- [ ] **B0. 사전 준비**: 데모 단어장 미리 세팅(빈/지저분 화면 금지) · 라이트 테마 고정 · 상태바 정리 · 세로 가능하면 60fps (iOS 내장 녹화 / Android 내장·`scrcpy`)
- [ ] **B1. 편별 녹화 대상** (스크립트의 `[화면 녹화]` 컷만):

  | 편 | 녹화 흐름 |
  |---|---|
  | 1편 자동완성 | add-word 검색창 `ephemeral` 타이핑 → enrich → 뜻·예문·발음·품사 채워짐 |
  | 2편 사진 | 카메라로 영어 교재 비춤 → 추출 리스트 → 완성 단어장 |
  | 3편 자동생성 | 주제 `여행 영어 20개` 입력 → 생성 → 20개 세트 좌르륵 |
  | 4편 학습 | 카드 뒤집기+좌/우 스와이프 → 퀴즈 정답 → 예문+자동재생 섀도잉 |

- [ ] **B2. AI 지연 처리** ⭐ enrich/generate/scan은 실제로 몇 초 걸림 → 녹화 후 **CapCut에서 speed-up** 하거나 "비트 드롭+휙" 전환으로 가림 (답답함 제거)

### Phase C — 마스코트 컷 생성 (Gemini/Veo)
- [ ] **C1. 1컷 검증 먼저** (쿼터 절약): Gemini 입력창 도구 → "동영상(Video)" → 1편 인트로 1컷만 생성해 워크플로우 검증
- [ ] **C2. 이미지 첨부 분기**: (A) 영상에 이미지 첨부 가능 → A1 캐릭터 첨부 + 모션 프롬프트 → 캐릭터 고정 ✅ / (B) 텍스트만 → 외형 묘사 생성, 일관성 깨지면 **Flow 전환**(참조 이미지 고정 확실)
- [ ] **C3. 모션 프롬프트** (공통 토큰 + 첨부 캐릭터):
  - 공통 토큰: `귀여운 3D 아보카도 마스코트(둥근 초록 몸, 큰 갈색 씨앗 배, 동그란 눈, 잎 손). warm cream/틸 배경, 밝고 경쾌, 부드러운 조명, 매끄러운 애니메이션. 9:16 세로. 화면에 글자 없음.`
  - 1편 인트로: `화면 아래에서 통통 튀어 올라와 카메라를 보고 잎 손을 흔든다. 살짝 갸웃. 가벼운 바운스.`
  - 1편 시그니처: `떠 있는 빛나는 알파벳 한 글자를 입으로 꿀꺽 삼키고, 반짝이는 단어 카드를 톡 뱉어낸다. 만족스러운 미소.`
  - 2편 시그니처: `셔터를 누르자 화이트 플래시가 터지고, 종이 위 글자들이 빛나며 떠올라 휴대폰 화면 속으로 빨려 들어간다.`
  - 3편 시그니처: `마법사 모자를 쓰고 지팡이를 휘두르자 모자에서 빛나는 단어 카드들이 분수처럼 솟아오른다.`
  - 4편 시그니처: `도장을 들고 카드에 쾅쾅 찍자 도장 자국에서 별이 사방으로 튄다. 자신감 있는 표정.`
  - 끝 카드 컷(각 편): 마스코트 엄지 척 / 윙크 / 카드 안기 / 카드 들어올리기 → 글자는 CapCut에서
- [ ] **C4. 검증 OK → 나머지 컷 확장** (편당 인트로+시그니처+끝카드 포즈). ⚠️ 클립당 쿼터 차감 → 만족 컷만 확장, 드리프트 시 Flow

### Phase D — CapCut 조립 (편당, 스크립트 0~22초 표대로)
- [ ] 클립 배치: Veo 컷 + 화면 녹화를 **음악 비트에 맞춰** 컷
- [ ] AI 지연 구간 speed-up (B2)
