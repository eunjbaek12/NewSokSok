# 사다리 4덱 — 캐시 뜻 O/X 판정표 (72건)

**무엇을 정하는가**: 덱이 가르치는 단어와 캐시가 설명하는 단어가 **같은 단어인가**.
같으면 캐시의 한국어 뜻풀이를 카드에 채우고, 다르면(동음이의) 비운다.

- **O** — 같은 단어다 → 채운다 (46건)
- **X** — 다른 단어이거나 일부만 맞다 → **비운다** (26건)

> 애초에 △(일부만 맞음) 9건을 따로 뒀으나, **빼기로 확정**했습니다.
> 이유: 9건 때문에 "이 단어는 캐시 ②번만"이라는 예외 표를 코드에 심어야 하는데,
> 잃는 건 3,168장 중 9장의 한국어 뜻풀이뿐입니다.

**"비운다"는 손대지 않는다는 뜻이 아닙니다.** 26건 중 11건은 지금 `definition` 자리에
영어 뜻이 복사돼 있어 카드에 **영어가 두 번** 뜹니다(레딧 제보 ④). 이건 지워야 합니다.
