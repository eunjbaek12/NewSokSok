1. 앱 내에서 계정 삭제하기

본 앱은 사용자가 앱 안에서 직접 계정과 모든 데이터를 영구 삭제할 수 있는 기능을 제공합니다.

  1. 1단계. 아보카도 앱을 실행하고 Google 계정으로 로그인합니다.
  2. 2단계. 하단 탭에서 "설정"을 누릅니다.
  3. 3단계. "계정" 섹션에서 화면을 아래로 스크롤합니다.
  4. 4단계. 가장 아래의 "계정 탈퇴"를 누릅니다.
  5. 5단계. 안내 메시지를 확인한 후 "탈퇴하기"를 눌러 확정합니다.

3. 삭제되는 데이터

계정 탈퇴 시 다음 데이터가 영구적으로 삭제되며 복구할 수 없습니다.

데이터 유형 처리
계정 정보 (이메일, 이름, 사용자 ID) 즉시 영구 삭제
모든 단어장 (클라우드 동기화된 항목) 즉시 영구 삭제
학습 진행 기록 (정답·오답·암기 상태) 즉시 영구 삭제
설정 및 환경설정 즉시 영구 삭제
본인이 단어 모음(커뮤니티)에 공유한 단어장 즉시 영구 삭제
결제 영수증 (Pro 구독 시) 법령상 보관 의무 기간 후 삭제 (전자상거래법 5년)
개발자에게 보낸 문의와 받은 답장 계정과의 연결(사용자 ID)은 즉시 끊김 · 내용은 접수일로부터 1년 후 삭제 (결제·환불 분쟁 대비)
참고: 다른 사용자가 이미 본인의 공유 단어장을 가져간 사본은 그 사용자의 단어장으로 남으며, 본인 계정 삭제와 무관하게 유지됩니다 (사본 시점에 분리됨).
예외 — 무료 체험 재취득 방지: 7일 Pro 무료 체험의 반복 재취득(탈퇴 후 재가입)을 막기 위해, 가입에 사용한 이메일 주소를 복원 불가능한 일방향 해시(SHA-256) 형태로만 보관합니다. 원본 이메일·이름 등 식별 가능한 개인정보는 위 표대로 즉시 영구 삭제되며, 보관되는 해시값으로는 이메일을 역산하거나 개인을 식별할 수 없습니다. 이 값은 오직 체험 중복 부여 차단 용도로만 사용됩니다.

3-1. Pro 구독 사용자 안내

현재 Pro 구독을 사용 중인 경우, 계정 삭제는 구독을 자동으로 해지하지 않습니다. 두 가지 절차를 별도로 진행해야 합니다.

  1. 1단계 — Pro 구독 해지: Android — Google Play 앱 → 메뉴 → 결제 및 정기 결제 → 정기 결제. iOS — 설정 앱 → 사용자 이름 → 구독. 여기에서 "아보카도" 구독을 해지합니다.
  2. 2단계 — 계정 삭제: 위 1번 절차에 따라 앱 내에서 또는 이메일로 계정 삭제를 요청합니다.
주의: 구독을 먼저 해지하지 않고 계정만 삭제하면 스토어(Google Play·App Store) 측 정기 결제는 계속 진행됩니다. 결제·환불은 결제한 스토어의 환불 정책을 따르며, 해당 스토어 고객센터로 직접 연락해 주세요.

4. 일부 데이터만 삭제하기

계정 전체를 유지하면서 일부 데이터만 삭제하고 싶은 경우, 앱 내에서 직접 수행할 수 있습니다.

  • 단어장 개별 삭제: 단어장 화면에서 단어장을 길게 누른 후 "삭제" 선택
  • 단어 개별 삭제: 단어 상세에서 "삭제" 선택
  • 공유 단어장 회수: 단어 모음에서 본인이 공유한 단어장을 "공유 취소"
  • 로그아웃: 설정 → 계정 → "로그아웃" (데이터는 클라우드에 유지되며 재로그인 시 복원)

5. 게스트 모드 사용자

게스트 모드(Google 로그인 없이 사용)는 클라우드에 데이터를 저장하지 않으며, 모든 데이터가 본인의 기기 안에만 존재합니다.

  • 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.
  • 설정 → "앱 데이터 초기화"로 데이터만 삭제하고 앱은 유지할 수 있습니다.
