# App Store Connect 등록 텍스트 — 한국어

App Store Connect → 앱 → App Store → 한국어(대한민국) 로케일에 그대로 붙여넣기.

> Play Console과 다른 점:
> - 부제(30자)·키워드(100자)·홍보 텍스트(170자)가 **별도 칸**으로 분리 — ASO 최적화 폭이 더 큼
> - "광고/결제 포함 여부"는 별도 필드 없이 **App Privacy(개인정보 보호) 설문**으로 처리
> - 가격은 KRW 직접 입력 불가, **가격 등급(Tier)** 선택 → 아래 매핑 참조

## 앱 이름 (최대 30자, 검색 가중치 ★★★)

```
아보카도: 영어 단어장·토익 수능 암기
```

> 21자(한도 30자). 검색 가중치 1위 자리에 한국 최대 검색어(영어·단어장·토익·수능·암기) 집중. Play Console과 동일 유지. "아보카도" 브랜드 유지하되 뒤에 고검색 키워드 배치.
> ⚠️ 제목에 토익·수능·단어장·암기가 들어갔으므로 아래 **키워드 칸에서 중복 제거 후 새 키워드로 교체** 가능(중복 단어는 키워드에서 빼도 검색됨).
>
> 📌 **다음 버전 제출 때 교체 확정**: `아보카도: 영어·일본어 단어장 토익 수능`(22자)
>
> **iOS 앱 이름은 버전 메타데이터라 새 버전 제출로만 바뀐다**(1.2.0 승인 후 잠김). Play는 앱 상세정보에서
> 언제든 바꿀 수 있지만, 두 스토어 이름을 맞추려고 **iOS 다음 버전에 Play도 함께** 교체하기로 했다.
>
> **교체 시 같이 손볼 것** — 제목에 `일본어`가 들어가면 아래 두 칸에 중복이 생긴다.
> Apple은 제목·부제·키워드를 자동 재조합하므로 중복 토큰은 그냥 낭비다:
> - **키워드**: `일본어` 제거 → 남는 자리에 새 토큰(예: 받아쓰기·간격반복·어원 등) 투입
> - **부제**: `수능·토익`이 제목과 겹침 → 다른 각도(예: 복습·6개국어·OCR)로 재구성 검토

아보카도는 한 곳에서 만들고 외우는 깔끔한 어휘 학습 도구입니다. 한국어·영어·일본어·중국어·베트남어·스페인어 6개 언어, 학습 방향은 자유롭게.

• 4가지 학습 모드
- 플래시카드: 카드 한 장씩 직관적으로
- 퀴즈: 객관식·주관식으로 빠르게 점검
- 예문 학습: 단어를 문장 속에서 익혀 활용도까지
- 오토플레이·쉐도잉: 듣고 따라 말하며 발음과 청취 동시에

• 학습하기 — 매일의 흐름
- 매일 학습할 단어 수를 정하면 자동으로 분배되는 암기 계획
- 학습률과 암기율을 직관적인 그래프로 확인
- 잘 외운 단어와 헷갈리는 단어를 구분해 복습 효율을 높여요
- 별표한 단어, 틀린 단어만 따로 모아 다시 학습

- 지금까지의 기록을 이미지로 저장해 자랑하기

• 사진·엑셀로 빠른 단어 추가
- 사진 한 장으로 단어를 통째로 가져오기
- 엑셀(CSV) 파일을 그대로 붙여넣거나 가져오기
- 일괄 붙여넣기: 줄바꿈된 단어 목록을 한 번에 추가
