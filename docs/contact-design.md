# 개발자에게 메시지 — 설계

화면 목업(SoT): https://claude.ai/code/artifact/dab24c39-4b99-47f3-ac75-abbbd4963bfe

거기 그려지지 않은 화면·상태·문구는 구현하지 않는다. 추가하고 싶은 게 생기면
코드가 아니라 목업을 먼저 고친다.

## 핵심 결정과 이유

**답장은 앱이 정본, 메일은 덤.** 이메일을 적지 않은 사용자(게스트 다수)에게는 앱이
유일한 경로다. Apple "이메일 가리기"(`@privaterelay.appleid.com`)는 등록된 발신자만
통과시키므로, 도메인 인증 전에는 메일이 반송될 수 있다. 그래서 화면 문구도
"메일로 답장드려요"가 아니라 "앱에서 보실 수 있어요"다.

**운영자는 `reply_body` 한 곳에만 쓴다.** update 웹훅이 같은 Edge를 다시 태워
메일로도 보낸다. 알림 메일에 직접 답장하면 앱에는 안 뜨고 이메일 없는 사용자에게는
아예 가지 않는다.

**벨·알림함·원격 푸시는 만들지 않는다.** 답장은 설정 행 배지가, 소식은 첫 실행
시트가 각각 더 잘 한다. 상시 그릇을 만들면 소식이 뜸해질 때 방치가 눈에 보인다.
푸시는 `plugins/withNoApsEnvironment.js`를 되돌려야 하는데(build 30 서명 실패의
원인), 월 몇 건의 답장에 치를 값이 아니다.

**소식은 서버가 아니라 번들.** 업데이트 소식은 정의상 업데이트할 때만 생기므로,
`constants/announcements.ts` 배열이면 다국어·버전 타게팅·오프라인 처리가 공짜다.
긴급 공지가 필요해지는 날 테이블을 얹고 화면은 그대로 쓴다.

**앱 쪽 전송 쿨다운은 없다.** 봇은 앱 화면을 거치지 않으니 클라이언트 제한은 막고
싶은 것을 못 막고 연달아 쓰는 정상 사용자만 막는다. 방어는 DB 트리거의 하루 5건
한 곳뿐이다.

**카테고리는 강제하지 않는다.** 내용 5자만 넘으면 보낼 수 있고, 안 고르면 `other`로
간다. 분류는 운영자 편의지 사용자 숙제가 아니다.

**멱등 `id`.** 클라이언트가 만들어 보내므로, 전송 타임아웃 뒤 재시도해도 23505로
튕겨 중복 문의가 생기지 않는다.

## 릴리스 때 할 일

1. `constants/announcements.ts`의 `version`·`date`를 `app.json`과 맞춘다.
   **버전이 다르면 시트가 뜨지 않는다**(틀린 소식을 띄우느니 안 띄우는 편이 낫다).
2. 사용자가 체감하는 변화만 세 줄 이내로. 버그픽스만 있으면 항목을 안 적으면 된다.
3. 개인정보 처리방침(`docs/privacy-policy.html`)에 문의 내용·회신 이메일·진단 정보의
   수집 목적과 보관기간(1년)을 추가한다.
4. Play **데이터 세이프티**에 "이메일 주소"·"기타 사용자 생성 콘텐츠",
   App Store **앱 개인정보**에 "고객 지원" 목적을 등록한다. 메타데이터라 새 빌드는
   필요 없다.

## 배포 순서

1. `supabase db push` — 테이블·RLS·RPC·트리거
2. Resend 계정 + secrets (`supabase/functions/notify-support/README.md`)
3. `supabase functions deploy notify-support --no-verify-jwt`
4. Database Webhook 두 개(INSERT·UPDATE) 등록

## 실기 검증 목록

- [ ] 게스트로 문의 전송 → 운영자 메일 도착(`[쏙쏙보카·…·회신불가]`)
- [ ] 대시보드에서 `reply_body` 작성 → 설정 행에 배지 + 문의 화면에 답장 카드
- [ ] 답장 아래에서 이어서 전송 → 메일 제목에 `[이어서]`, 이전 문답 인용
- [ ] 비행기 모드에서 전송 → 실패 다이얼로그, **입력이 남아 있는지**, 메일 폴백
- [ ] 하루 6번째 전송 → "오늘은 여기까지 보낼 수 있어요"
- [ ] 진단 정보 토글을 끄고 전송 → 메일에 "진단 정보 없음"
- [ ] 설정 → 개발자 → "새로운 소식 다시 보기" → 홈에서 시트
- [ ] 시트가 뜬 세션에서 학습 결과 화면의 리뷰 넛지가 뜨지 않는지
- [ ] 다크 테마에서 문의 화면·시트
- [ ] **preview 프로필(릴리스 APK)로 볼 것** — 릴리스에서만 패딩이 무너진 전례가 있다
