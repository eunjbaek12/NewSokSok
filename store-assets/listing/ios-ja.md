# App Store Connect 등록 텍스트 — 일본어 (ja-JP)

대상: **한국어를 배우는 일본 사용자** (K-POP·韓流·留学). App Store Connect → 앱 → App Store → 일본어 로케일 추가 후 붙여넣기.

> App Store 검색은 **앱 이름 + 부제 + 키워드 필드**만 인덱싱(설명문은 랭킹 무관, 전환용). 그래서 이 3개 칸이 핵심.
> Apple은 키워드 토큰을 **자동 조합**하므로 이름·부제에 쓴 단어는 키워드에서 빼서 공간 절약.

```

```

> 18자. "韓国語"(한국어)·"単語帳"(단어장)·"TOPIK"·"単語暗記"(단어암기) — 일본 내 한국어 학습 최대 검색어를 제목에. 브랜드는 アボカド(아보카도, 아이콘과 일치).
