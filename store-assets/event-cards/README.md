# App Store 인앱 이벤트 카드 이미지

10월 인앱 이벤트 ②(한글날)·③(할로윈)에 올릴 이미지. 규격·일정·이벤트 자체의 판단 근거는
[`store-assets/featuring-nomination.md`](../featuring-nomination.md) §10 에 있다.

## 왜 필요한가

이벤트 **등록에 필수**다. 이미지 없이는 App Store Connect 에서 이벤트를 만들 수 없다.
걸리는 자리는 넷 — 앱 제품 페이지의 이벤트 섹션 · 검색 결과 · Today/Apps 탭의 에디터
큐레이션 · 이벤트 링크를 공유했을 때의 미리보기. 스크린샷·아이콘에 이은 **세 번째 표지**다.

## 무엇이 들어가는가

| | |
|---|---|
| **16:9** 1920×1080 | 카드 이미지. 지나가다 보는 자리라 **단어 하나**를 크게 세운다 |
| **9:16** 1080×1920 | 상세 이미지. 이미 눌러 들어온 자리라 **카드 셋**으로 덱을 보여 준다 |

이벤트 ①(Major Update)만 다르다 — 실체가 덱이 아니라 1.7.0 의 새 기능이라 **스킨 3종을 나란히**
세운다(`major-*.png`). 글자가 하나도 없어 **한국·미국을 한 벌로 덮는다**.

카드 안은 세 칸뿐이다 — **표제어 · 로마자 · 영어 뜻**. 앱의 학습 카드가 보여 주는 것과 같다.

🔴 **이미지에 배지·홍보 문구를 넣지 않는다.** 스토어가 이벤트 **이름(30자)과 짧은 설명(50자)을
이미지 위에 얹으므로** 같은 말이 두 번 나오고, 무엇보다 그런 문구는 **로케일마다 다시 뽑아야
한다**. 표제어·로마자·영어 뜻은 덱이 가르치는 내용이라 어느 스토어프론트에서도 그대로 선다
— 그래서 이벤트당 두 장으로 끝난다(초안의 「50 new words」 판은 여덟 장이 될 뻔했다).

세울 단어는 계기와 맞물린 것으로 골랐다: 한글날 = **훈민정음**(한글날이 이 문서의 반포일이다) ·
할로윈 = **도깨비**(3글자라 작게 줄어도 읽히고 드라마로 이미 알려졌다).

## 만드는 법

```bash
node store-assets/event-cards/render.mjs --final          # 확정본 8장 → final/
node store-assets/event-cards/render.mjs                  # 후보 A·B·C·D 전량 → out/
node store-assets/event-cards/render.mjs --only horror     # 한 이벤트만
```

`store-assets/screenshots/compose.mjs` 와 같은 방식이다 — HTML 을 그려 Playwright 크로미움으로
정확한 픽셀 크기에 찍는다. 재료는 전부 앱에서 가져온다(스킨 배경 webp · 스킨 팔레트 ·
스킨 글꼴 · 덱의 진짜 단어). 카드가 앱과 다른 얼굴이면 스토어에서 보고 들어온 사람이 다른
앱을 만난다.

## 함정 (겪은 것)

- 🔴 **글꼴·그림은 base64 로 심어야 한다.** 저장소 경로에 한글(`문서`)이 들어 있어 `file://`
  URL 이 크로미움에서 **조용히** 실패한다. 오류도 없이 기본 산세리프로 그려질 뿐이라, 명조로
  그린 줄 알았던 한글 카드가 고딕으로 나온다.
- 🔴 **npx 캐시의 playwright 가 기대하는 브라우저 빌드가 없다.** 한 세대 전 것이 이미 깔려
  있으므로 `executablePath` 로 그것을 가리킨다(`npx playwright install` 로 100MB 를 더 받지
  않는다). 경로는 `render.mjs` 맨 위 `CHROME`.
- 🔴 **스킨 배경은 SVG 가 아니라 1080×2340 webp 다.** 9:16 은 원본에서 잘라 쓰면 되지만
  16:9 는 1.78배 확대다 — 문양이 평면이라 견디고, 스토어에서 작게 보여 티가 안 난다.
- ✅ **할로윈 카드의 캐릭터는 박쥐 망토를 입는다**(9/9). `components/CharacterAccessory.tsx` 의
  `HalloweenCape` 를 평범한 SVG 로 옮겨 캐릭터 SVG 의 **마지막 자식**으로 끼운다 — 앱이 `<Svg>`
  안에 얹는 것과 같은 자리라 겹치는 순서(망토가 몸 위)가 저절로 같아진다. RN → SVG 에서 바뀌는
  것은 셋뿐이다: 태그 대소문자 · 속성 이름(`strokeWidth`→`stroke-width`) · transform 배열
  (`[{translateX:250},{scaleX:-1}]`→`translate(250 0) scale(-1 1)`).
  🔴 **치수는 옮기기만 하고 고치지 않는다.** 팔 끝에서 +9(x26) 같은 값은 앱에서 실측으로 맞춘
  것이라 여기서 손대면 둘이 갈라진다. 반대로 앱에서 안 보이던 것이 여기선 보인다 — 망토가
  앱에선 56dp 지만 카드에선 300~430px 라 주름 한 줄이 1px 이 아니라 4px 다. **보기 좋으라고
  이쪽 값을 바꾸면 56dp 쪽이 망가진다.**
- 한글날 카드의 캐릭터는 갓을 안 썼다. 같은 방법으로 옮길 수 있지만(`HangulGat`), 갓은 치수가
  계산식이라 값을 풀어 적어야 한다 — 아직 안 했다.

## 스토어프론트 — 한국·미국 (은정님, 2026-09-09)

| 이벤트 | 지역 | 실체 | 이미지 |
|---|---|---|---|
| ① Major Update 10/1~10/31 | **한국 · 미국** | 1.7.0 새 기능(스킨 3종·완주 자랑하기·접근성) | `major-*` |
| ② 한글날 10/9~10/16 | **미국** | `curated-hangul-ko-1` | `hangul-*` |
| ③ 할로윈 10/25~10/31 | **미국** | `curated-horror-ko-1` | `horror-*` |
| ③-KR 할로윈 10/25~10/31 | **한국** | `curated-halloween-en-1` 「할로윈 영어 50」 | `halloween-en-*` |

🔴 **덱 이벤트는 한국 스토어에 걸 수 없다 — 눌러 들어와도 그 덱이 안 보인다.**
공식 덱은 사용자의 「뜻 언어」와 덱의 `targetLanguage` 가 같을 때만 목록에 뜬다
(`features/curation/screen.tsx:632-637`). 한국 사용자는 뜻 언어가 한국어라 `targetLanguage='en'`
인 두 덱이 걸러지고, 「뜻 언어를 바꾸면 덱이 있다」는 안내는 **목록이 통째로 비었을 때만** 뜨는데
한국어 덱이 많아 목록이 안 빈다. 그래서 한국 몫은 언어를 안 타는 ① 이 맡는다.

✅ **한국 몫 덱을 만들었다(9/9)** — `curated-halloween-en-1` 「할로윈 영어 50」(en>ko).
같은 할로윈이지만 방향이 반대다: 미국 몫은 「한국의 귀신」을 영어권에 가르치고, 한국 몫은
할로윈 영어를 한국인에게 가르친다. 카드도 그래서 갈린다 — 한국용은 표제어가 영어(`trick or
treat`)이고 밑에 한글 발음과 한국어 뜻이 붙는다.
