# 콘텐츠 등급 설문 답변지

Play Console → 앱 콘텐츠 → **콘텐츠 등급(Content rating)** 설문 답변.

IARC(International Age Rating Coalition) 표준 질문에 답하면 ESRB·PEGI·USK·GRAC 등 각 지역별 등급이 자동 산정됩니다.

---

## 카테고리 선택

처음에 카테고리를 묻습니다:
- **Reference, News, or Educational** ← 선택 (Education 앱)

또는
- **All other app types** 도 가능 — 어휘 학습이므로 Educational이 더 적합

## App Store(iOS) 연령 등급 설문 — "특징" 답변지 (2026-07-13 실제 입력)

⚠️ 이 섹션은 **Apple App Store Connect**의 2025년 개편 연령 등급 설문이다 (Google Play IARC 아님).
식별 단서: "**Declared Age Range API**" 언급 = Apple 2025 도입 기능. Apple은 결과를
**4+ / 9+ / 13+ / 16+ / 18+** 밴드로 산정한다(ESRB/PEGI 아님).

Apple 설문은 IARC 콘텐츠 질문 외에 앱 **특징(capabilities/features)**을 별도로 묻는다.
아래 답은 "앱이 실제로 무엇을 하는가"에 대한 사실이라 iOS/Android 공통이다. 각 항목 아니요/예:

### 앱 내 제어
| 항목 | 답 | 근거 |
|---|---|---|
| 유해 콘텐츠 차단 (보호자 관리 도구) | **아니요** | 보호자용 모니터링/제한 설정 없음 |
| 나이 확인 | **아니요** | 연령 수집·확인 안 함 (14+ 타깃, 연령 미수집) |

### 제공 기능
| 항목 | 답 | 근거 |
|---|---|---|
| 제한되지 않은 웹 액세스 | **아니요** | 네이버 사전 등 특정 URL만 오픈. 주소창·자유 브라우징 없음 |
| 사용자 생성 콘텐츠(UGC) | **예** | 커뮤니티 큐레이션 — 사용자 단어장 공개 공유 |
| 소셜 미디어 | **아니요** | 피드·팔로우·바이럴 확산 없음 (공유 라이브러리) |
| 13세 미만 사용자의 소셜 미디어 비활성화 | **아니요** | 소셜 미디어 기능 자체가 없어 해당 없음 |
| 메시지 및 채팅 | **아니요** | 사용자 간 직접 대화 기능 없음 |
| 광고 | **예** | AdMob 배너 + 리워드 (무료/게스트 대상) |

> UGC=예 → 뒤 단계에서 신고/중재 후속 질문 나옴 → 둘 다 Yes (아래 "사용자 상호작용" 참조).
> 광고=예 → 광고 형식/타깃팅 질문은 App Store **앱 개인정보(App Privacy)** 라벨과 일치하게 답할 것 (iOS).
> Play 제출 시 같은 답을 Google **Data Safety** 폼과 일치시키면 됨.

## 설문 항목별 답변

### 폭력 관련
- 폭력적 콘텐츠 포함? **No**
- 현실적 폭력 묘사? **No**
- 무기 사용 묘사? **No**

### 성적 콘텐츠 관련
- 노출/누드? **No**
- 성적 콘텐츠/암시? **No**
- 사용자 간 채팅이나 메시지? **No**

### 모독적 언어
- 욕설/비속어 포함? **No**
- 그러나 **사용자가 직접 단어를 입력**할 수 있다는 점은 별도 고려:
  - 단어장은 사용자 본인의 학습용이므로 사적 영역
  - 큐레이션 공유 시에만 다른 사용자에게 보임 (신고 기능 + 관리자 삭제로 중재 가능 — 위 "사용자 상호작용" 참조)

### 약물 관련
- 약물·알코올·담배 묘사? **No**

### 도박 관련
- 도박/베팅 콘텐츠? **No**
- 시뮬레이션 도박? **No**
- 무작위 보상(가챠) 시스템? **No**

### 사용자 상호작용
- **사용자가 콘텐츠를 다른 사용자와 공유할 수 있나요?** ✅ **Yes** (커뮤니티 큐레이션)
- **사용자의 위치를 다른 사용자와 공유하나요?** ❌ No
- **개인정보를 사용자가 디지털 콘텐츠로 공유하나요?** ❌ No

> ✅ **사용자 콘텐츠 공유에 "Yes" 답변 시 추가 질문** (2026-07-13 기준 최신):
> - **콘텐츠 신고 메커니즘이 있나요?** **답변: Yes** — `features/curation/ReportCurationModal.tsx` 구현됨. 로그인한 비소유자가 상세 헤더의 flag 아이콘 → 사유(부적절/저작권/스팸/허위정보/기타) 선택 + 상세 500자. `features/vocab/api.ts:reportCuration` → `curation_reports` 테이블(migration `20260522000000_curation_reports.sql`).
> - **관리자 검토 메커니즘이 있나요?** **답변: Yes** — `app_admins` 테이블 기반 관리자가 임의 큐레이션 삭제 가능.
>
> ⚠️ 과거 이 문서는 "신고 미구현 → No"라고 적혀 있었으나, 신고 기능이 이후 추가되어 정정함. UGC 관련 후속 질문엔 모두 **Yes**로 답할 수 있음.

### 디지털 구매
- 디지털 상품·서비스 판매? **No**

### 위치
- 사용자 위치 데이터 수집/공유? **No**

### 개인 정보
- 이름·이메일·전화번호 등 수집/공유? **Yes** (Google 로그인 시 이메일·이름)
  - → Data Safety 폼과 일치하게 답변

### 공포·테러
- 공포감 유발 콘텐츠? **No**

### 모방 위험
- 사용자가 위험한 행동을 따라할 가능성? **No**

## 예상 등급

위 답변 기준 예상 등급:

| 지역 | 등급 |
|---|---|
| ESRB (북미) | **Everyone** |
| PEGI (유럽) | **PEGI 3** |
| USK (독일) | **USK 0** |
| GRAC (한국) | **전체이용가** |
| IARC Generic | **3+** |

사용자 콘텐츠 공유로 인해 일부 지역에서 등급이 약간 올라갈 수 있으나, 학습 앱 특성상 **3+/Everyone**으로 정착하는 게 일반적.

> ✅ **App Store 실제 산정 결과 (2026-07-13, 1.1.5 설문 편집 후):** 4+ (172개국 글로벌) · 브라질 12 (자국 ClassInd, 광고 요인) · 한국 전체이용가(00+) · 베트남 모든 연령. 예상보다 낮게(대부분 4+) 나옴 — 신고 기능·채팅 없음·자유 웹 없음 덕. 조치 불필요.

## 추가 정보 (선택 입력)

콘텐츠 등급 설문 마지막에 "추가 정보" 박스가 있으면:

```
아보카도는 한국어·영어·일본어·중국어 어휘 학습을 위한 개인 학습 도구입니다.
사용자가 직접 단어장을 만들거나 커뮤니티에서 공유된 단어장을 가져올 수 있으며,
모든 콘텐츠는 학습 목적입니다. 관리자가 부적절한 큐레이션을 삭제할 수 있습니다.
```
