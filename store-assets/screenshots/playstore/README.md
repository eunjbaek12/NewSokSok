# Google Play 폰 스크린샷 (cream 스타일)

Play Console 업로드용 7장 스크린샷 캡처·합성 가이드. iOS `appstore/`와 **같은 cream 디자인**이되 Play 규격(비율 최대 2:1)에 맞춰 세로만 줄인 버전.

## iOS와 다른 점

| | iOS `appstore/` | Android `playstore/` |
|---|---|---|
| 해상도 | 1290×2796 (2.167:1) | **1290×2580 (정확히 2:1)** |
| 이유 | App Store는 긴 비율 허용 | **Play는 비율 최대 2:1까지만 허용** |
| 출력 슬롯 | 6.9" + 6.5" 두 종 | 단일 (폰 스크린샷) |
| 장수 | **9장** | **7장** |
| 라인업 | 01~09 | **01~07 (iOS의 08/09-theme 2장 제외)** |
| 캡션 | 동일 | 동일 (공유 01~07 캡션 텍스트) |

캡션 문구를 바꾸면 두 파이프라인 config.json을 **둘 다** 고쳐야 함(01~07은 의도적으로 복제, iOS만 테마 2장 추가).

## 디렉토리

```
playstore/
├── config.json      — 7장 메타데이터 (캡션 ko/en + 캡처 힌트 + 팔레트)
├── template.html    — cream 합성 디자인 (배경+캡션+기기목업+상태바 더미)
├── compose.mjs      — raw → final 자동 합성 (Playwright)
├── raw/             — 직접 캡처한 원본 (gitignore 권장)
│   ├── ko/ 01-home.png … 07-curation.png
│   └── en/ 01-home.png … 07-curation.png
└── final/
    └── {ko,en}/     — 1290×2580 합성 결과 (Play 업로드용)
```

## 사양

- **해상도**: 1290×2580 (2:1). Play 폰 스크린샷 요건(각 변 320~3840px, 비율 ≤ 2:1) 충족
- **장수**: 7장 / 언어 (한 + 영 = 14장). Play는 언어별 최대 8장
- **포맷**: 24-bit PNG, 알파 없음 (compose.mjs가 자동 처리)

## 1. 캡처 (안드로이드 실기 + 최신 빌드)

### 공통 수칙
- **안드로이드로 캡처** (Play용이므로 안드로이드 화면 OK). *(1.2.0 신규 06-stats는 iOS 캡처 재사용도 가능 — 상태바 확인 필요, 상세 아래 ⚠️.)*
- **라이트 테마 고정** (7장 전부 라이트. Play 라인업엔 테마 스크린샷 없음).
- **콘텐츠가 다 뜬 걸 확인하고 캡처** (로딩 중 캡처 금지).
- 상태바(시간·배터리·알림 아이콘)는 **합성 때 9:41 더미로 자동 교체**되니 신경 안 써도 됨.
- 하단 **제스처 네비게이션 권장** (3버튼 네비바는 폰 목업 하단에서 잘리거나 지저분). 캡처에 네비바가 들어가도 목업 하단에서 자연히 잘림.
- 깨끗한 데모 데이터로 (빈/지저분 화면 금지).
- 캡처: 전원 + 볼륨 다운 동시 → 사진/갤러리 → PC 전송.

### 장별 캡처 대상

| ID | 화면 | 캡처할 상태 | 주의 |
|---|---|---|---|
| `01-home` | 홈 탭 | 단어장 2~3개 진행 중 + 진척 보이게 | 복습 배너 안 나와도 됨(설명 텍스트로 홍보) |
| `02-autocomplete` | 단어 추가 | 뜻·예문·발음·품사 **자동완성 다 채워진** 순간 | 빈 칸 없이 |
| `03-photo` | 사진 스캔 결과 | 추출 리스트 + **"최종 저장하기" 버튼 정상** | ⚠️picker/갤러리 안 보이게, PII 금지 |
| `04-generate` | AI 단어 생성 | 주제 **"배 아플 때 병원 가서 쓰는 단어 20개"** → 결과 | 주제 텍스트 보이게 |
| `05-study` | 플래시카드 | 카드 펼쳐진 상태 (단어+뜻) | |
| `06-stats` | 내 학습(통계) | **연속 학습·달력·외운 단어** 보이게, 캐릭터 포함 | 🆕 1.2.0. 홈 통계 스트립 탭해서 진입 |
| `07-curation` | 단어 모음 | 큐레이션 카드들, **다국어 섞이게** | |

> 🆕 1.2.0 신규 캡처는 **06-stats 1장뿐**. 나머지(01~05·07)는 기존 raw 재사용(대기 없음). 복습은 별도 컷 없이 앱 설명·'새로운 기능' 텍스트로 홍보.

### 저장
캡처본을 아래 경로에 ID 그대로 저장 (확장자 소문자 `.png`):
```
raw/ko/01-home.png  …  raw/ko/07-curation.png
raw/en/01-home.png  …  raw/en/07-curation.png
```
> 앱 설정 → 언어를 한국어/English로 바꿔 같은 화면을 두 번 캡처.

## 2. 합성

```bash
# Playwright 필요 (미설치 시: npx playwright install chromium)
node store-assets/screenshots/playstore/compose.mjs   # 14장
```

raw가 일부만 있어도 있는 것만 합성하고 누락분은 스킵 → 추가 캡처 후 재실행.

### ⚠️ iOS 캡처를 재사용할 때 (06-stats 등)
- Play compose는 `captureStatusBarPx`(기본 80)를 **파이프라인 전체에 하나로** 적용 → 아이폰 캡처(상태바가 더 큼)를 그대로 넣으면 상단 더미 상태바가 실제 상태바를 덜 덮어 삐져나올 수 있음.
- 합성 후 해당 장 **맨 위를 확인**. 실제 상태바가 비치면: 그 장만 상단을 크롭하거나, 안드로이드로 재촬영.

### ⚠️ 캡처 해상도가 1080×2400이 아니면
- **상태바 높이가 안 맞으면**: `config.json`의 `captureStatusBarPx`를 캡처 원본의 실제 상태바 픽셀 높이로 조정 (기본 80).
- **폰 목업에서 화면이 너무 길게/짧게 잘리면**: `template.html`의 `.phone { width }`(기본 840px)를 조정. 캡처가 더 길쭉(20:9 이상)하면 width를 줄여 하단 잘림을 늘리고, 짧으면(18:9) 키움.
- 한 장 합성해 `final/`에서 확인 후 전체 돌리는 걸 권장.

## 3. Play Console 업로드

Play Console → 앱 → 기본 스토어 등록정보(또는 맞춤 스토어 등록정보) → **휴대전화 스크린샷**:
- `final/ko` 7장을 **01→07-curation 순서대로** (한국어 등록정보)
- `final/en` 7장 (영어 등록정보)
- 언어별 등록정보(현지화)에 각각 매칭
