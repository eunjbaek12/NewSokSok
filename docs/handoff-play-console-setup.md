# Play Console 앱 등록 가이드

쏙쏙 보카(아보카도)의 Play Console 신규 앱 등록 및 내부 테스트 출시 절차.

작성일: 2026-05-17 / 대상: v1.1 출시(광고·인앱구독 포함)

> ℹ️ 이 가이드는 **앱 신규 등록 시점**용. 이미 빌드된 AAB(versionCode 3)를 **내부 테스트 트랙**에 우선 올리고, v1.1 코드 작업 후 새 빌드로 업데이트하는 흐름.

---

## 전체 체크리스트

```
□ 0. 사전 준비 확인
□ 1. 앱 생성 (이름·언어·무료/유료)
□ 2. 스토어 등록정보 (앱 설명·스크린샷·아이콘·그래픽)
□ 3. 콘텐츠 등급 설문
□ 4. 타겟층 및 콘텐츠
□ 5. 데이터 보안 폼
□ 6. 광고 · 앱 액세스
□ 7. AI 생성 콘텐츠 공시
□ 8. AAB 업로드 (내부 테스트 트랙)
□ 9. Play App Signing SHA-1 → OAuth 등록 (Google 로그인용)
□ 10. 내부 테스터 등록 + 본인 기기 설치
□ 11. (v1.1 코드 작업 후) AdMob 연결
```

## 1. 앱 생성

### 1-1. Play Console 진입
```
https://play.google.com/console
```

### 1-2. "앱 만들기" 클릭
좌측 메뉴 → "모든 앱" → 우측 상단 **"앱 만들기"** 버튼

### 1-3. 앱 정보 입력
- **앱 이름**: `아보카도: 단어장 학습`
- **기본 언어**: 한국어 - 한국 (`ko-KR`)
- **앱 또는 게임**: 앱
- **무료 또는 유료**: **무료** (인앱구매 별도 등록)
- **선언 사항**:
  - ✅ 개발자 프로그램 정책 준수
  - ✅ 미국 수출법 준수
- **앱 만들기**

→ 패키지명 `com.soksokvoca`가 첫 AAB 업로드 시 자동 고정됨.

## 8. AAB 업로드 (내부 테스트 트랙)

### 8-1. 내부 테스트 트랙 진입
좌측 메뉴 → **"테스트 및 출시" → "테스트" → "내부 테스트"**

> 💡 **내부 테스트 트랙을 쓰는 이유**:
> - 심사 X, 즉시 사용 가능 (몇 분 내 설치 가능)
> - 본인 + 최대 100명 테스터에게 배포
> - 결제·광고 실제 동작 테스트 가능
> - 정식 출시는 모든 작업 끝난 후 "프로덕션 트랙으로 승격"

### 8-2. 테스터 목록 만들기
- "테스터" 탭 → **"이메일 목록 만들기"**
- 목록 이름: `내부 테스터`
- 이메일 추가: 본인 Google 계정 이메일 (예: `hskimiops@gmail.com`)
- **변경사항 저장**

### 8-3. 새 버전 만들기
- "릴리스" 탭 → **"새 버전 만들기"**

### 8-4. 서명 키 설정
- **"Play 앱 서명 사용"** 권장 (Google이 키 관리)
- 처음이면 자동으로 활성화됨

### 8-5. AAB 업로드
- **"App Bundle"** 영역에 AAB 파일 드래그
- 파일: 다운로드된 `application-XXXXX.aab` (Expo 빌드 결과)
- 업로드 후 자동 검증 (1~2분)

### 8-6. 릴리스 정보
- **릴리스 이름**: `1.0.0 (3)` 자동 입력됨 (versionCode 3)
- **출시 노트**:
  ```
  • 첫 내부 테스트 빌드
  • 단어장 학습 기본 기능
  ```

### 8-7. 저장 → 검토 → 출시
- "저장" → "버전 검토" → **"내부 테스트 트랙으로 출시 시작"**
- 검토 X, 즉시 게시 (몇 분)

- **"앱 서명"** 탭
- **"앱 서명 키 인증서"** 섹션의 **SHA-1** 복사

### 9-2. Google Cloud Console에 등록
- https://console.cloud.google.com/apis/credentials
- 프로젝트: `avocado-491710` (또는 OAuth 클라이언트가 있는 프로젝트)
- OAuth 2.0 클라이언트 ID 목록에서 **"Android"** 타입 클라이언트 클릭
  - 없으면 "사용자 인증 정보 만들기" → "OAuth 클라이언트 ID" → Android
- **패키지명**: `com.soksokvoca`
- **SHA-1 인증서 디지털 지문**: 위에서 복사한 SHA-1 붙여넣기

## 자주 막히는 부분

### "이 앱 번들은 이미 업로드되었습니다"
같은 versionCode AAB를 두 번 업로드 시도. 새 빌드 필요:
```
$env:EAS_SKIP_AUTO_FINGERPRINT=1; eas build --profile production --platform android
```
versionCode 자동 증분됨.

### "데이터 보안 폼이 불완전합니다"
모든 카테고리 답변 + 제3자 SDK 명시 필요. AdMob, Google Sign-In, Supabase 모두 명시.

### "콘텐츠 등급이 너무 낮습니다"
설문 답변에서 광고·결제 항목을 "아니요"로 한 경우. v1.1엔 광고·결제 있으니 정직하게 "예"로.

### Google 로그인 작동 안 함 (DEVELOPER_ERROR)
9단계 (SHA-1 → OAuth 등록) 누락. 반드시 진행.

### 내부 테스트 옵트인 후에도 Play Store에 안 보임
- 옵트인 URL을 안드로이드 기기에서 직접 열어야 함 (PC X)
- 옵트인 후 10~30분 기다리기
- Play Store 캐시 비우기 (설정 → 앱 → Play 스토어 → 저장공간 → 캐시 삭제)
