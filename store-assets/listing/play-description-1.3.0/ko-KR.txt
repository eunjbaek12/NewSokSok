내가 원하는 단어장은 직접 만들고, 내가 찾던 단어장은 모음에서 가져와서.
아보카도는 한 곳에서 만들고 외우는 깔끔한 어휘 학습 도구입니다. 영어 단어장은 물론 일본어·중국어·스페인어·베트남어 단어장까지, 학습 방향은 자유롭게.

• 4가지 학습 모드
- 플래시카드: 카드 한 장씩 직관적으로
- 퀴즈: 객관식·주관식으로 빠르게 점검
- 예문 학습: 단어를 문장 속에서 익혀 활용도까지
- 오토플레이·쉐도잉: 듣고 따라 말하며 발음과 청취 동시에

• 학습하기 — 매일의 흐름
- 매일 학습할 단어 수를 정하면 자동으로 분배되는 암기 계획
- 학습률과 암기율을 직관적인 그래프로 확인
- 잘 외운 단어와 헷갈리는 단어를 구분해 복습 효율을 높여요
- 별표한 단어, 틀린 단어만 따로 모아 다시 학습

• 부드러운 복습 — 잊을 때쯤, 딱 그때
- 외운 단어를 잊을 무렵 앱이 자동으로 다시 모아줘요
- 잘 외운 단어는 뜸하게, 자꾸 틀리는 단어는 자주 — 죄책감 없는 간격 반복
- 하루 분량엔 넉넉한 상한이 있어, 며칠 밀려도 한꺼번에 쏟아지지 않아요
- 복습할 단어가 있는 날에만 하루 한 번 살짝 알림 (없는 날은 조용히)

• 연속 학습 · 통계
- 연속 학습(스트릭)·달력·외운 단어를 '내 학습'에서 한눈에
- 오늘·이번 주·전체 외운 단어가 쌓이는 재미
- 지금까지의 기록을 이미지로 저장해 자랑하기

• 사진·엑셀로 빠른 단어 추가
- 사진 한 장으로 단어를 통째로 가져오기
- 엑셀(CSV) 파일을 그대로 붙여넣거나 가져오기
- 일괄 붙여넣기: 줄바꿈된 단어 목록을 한 번에 추가
- 음성 입력과 직접 입력도 물론 지원

• AI 단어 생성 & 자동 분석
- 주제만 입력하면 AI가 단어장을 통째로 만들어요
  예: "미국 부동산 계약", "카페에서 주문하기", "TOEIC 빈출 동사"
- 단어 1개를 추가하면 발음·뜻·예문·동의어까지 AI가 자동 생성
- 언어쌍, 난이도, 단어 개수까지 직접 설정
- 마음에 드는 단어만 골라 담고, 마음에 안 들면 같은 주제로 다시 생성

• 단어 모음에서 쉽게 다운
- 다른 학습자가 공유한 단어장 중에서 마음에 드는 걸 골라 바로 학습
- 공식 큐레이션 단어장 풍부하게 기본 제공
  · 영어 — NGSL(기초)·BSL(비즈니스)·NAWL·TSL(학술/시험)
  · 일본어 — 기초 500 · JLPT N3
  · 중국어 — HSK 1급
  · 한국어 — TOPIK 기초·중급·고급 3단 시리즈 (국립국어원 NIKL A/B/C 빈도, 외국인 학습자용 — K-pop·한류·유학 학습자에게 최적)
  · 한국어 — TOPIK II 필수 300 (TOPIK I을 마친 학습자를 위한 중급 300단어, 예문·연어 포함 / 뜻 언어 영어)
  · 베트남어 — 기초 500
  · 한국어 모국어용 — 자주 틀리는 맞춤법 100
- 잘 만든 내 단어장은 공유해 다른 학습자에게 도움 주기

• 다국어 단어장 — 어느 언어에서 어느 언어로든
- 영어 단어장, 일본어 단어장, 중국어 단어장, 스페인어 단어장, 베트남어 단어장을 한 앱에서
- 어떤 언어든 단어만 넣으면 AI가 뜻·예문·발음을 채워 줍니다
- 입력 언어와 뜻 언어를 자유롭게 조합 (한-영, 한-일, 영-중, 베-영, 한-베, 스-영 등 어떤 페어든)
- 한국어를 배우는 외국인 학습자(K-pop·한류·유학·이민)를 위한 한국어 단어장도 동일한 흐름
- 모국어가 무엇이든, 목표 언어가 무엇이든 — 세계 어디서나

• 나만의 스타일을 담은 스킨
- 클래식, 다크 고요, Y2K, 실험실, 여름 바다 등 다양한 테마
- 분위기를 바꿔 학습하는 시간이 더 즐거워요

• 클라우드 동기화 & 오프라인 우선
- 데이터는 기기에 먼저 저장돼 인터넷이 없어도 학습 가능
- Google 로그인 시 클라우드로 안전하게 동기화
- 게스트 모드는 가입 없이 즉시 시작
