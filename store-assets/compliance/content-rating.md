# 콘텐츠 등급 설문 답변지

Play Console → 앱 콘텐츠 → **콘텐츠 등급(Content rating)** 설문 답변.

IARC(International Age Rating Coalition) 표준 질문에 답하면 ESRB·PEGI·USK·GRAC 등 각 지역별 등급이 자동 산정됩니다.

---

## 카테고리 선택

처음에 카테고리를 묻습니다:
- **Reference, News, or Educational** ← 선택 (Education 앱)

또는
- **All other app types** 도 가능 — 어휘 학습이므로 Educational이 더 적합

---

## 설문 항목별 답변

### 폭력 관련
- 폭력적 콘텐츠 포함? **No**
- 현실적 폭력 묘사? **No**
- 무기 사용 묘사? **No**

### 성적 콘텐츠 관련
- 노출/누드? **No**
- 성적 콘텐츠/암시? **No**
- 사용자 간 채팅이나 메시지? **No**

### 모독적 언어
- 욕설/비속어 포함? **No**
- 그러나 **사용자가 직접 단어를 입력**할 수 있다는 점은 별도 고려:
  - 단어장은 사용자 본인의 학습용이므로 사적 영역
  - 큐레이션 공유 시에만 다른 사용자에게 보임 (자체 신고/관리 메커니즘은 약함)

### 약물 관련
- 약물·알코올·담배 묘사? **No**

### 도박 관련
- 도박/베팅 콘텐츠? **No**
- 시뮬레이션 도박? **No**
- 무작위 보상(가챠) 시스템? **No**

### 사용자 상호작용
- **사용자가 콘텐츠를 다른 사용자와 공유할 수 있나요?** ✅ **Yes** (커뮤니티 큐레이션)
- **사용자의 위치를 다른 사용자와 공유하나요?** ❌ No
- **개인정보를 사용자가 디지털 콘텐츠로 공유하나요?** ❌ No

> ⚠️ **사용자 콘텐츠 공유에 "Yes" 답변 시 추가 질문**:
> - **콘텐츠 신고 메커니즘이 있나요?** 현재 미구현. **답변: No**
> - **관리자 검토 메커니즘이 있나요?** `app_admins` 테이블 기반으로 관리자 삭제 가능. **답변: Yes (admin can delete)**
>
> Play Store는 UGC가 있는 앱에 신고 기능을 권장합니다. 출시 후 빠른 시일 내에 큐레이션 신고 버튼 추가를 고려해주세요.

### 디지털 구매
- 디지털 상품·서비스 판매? **No**

### 위치
- 사용자 위치 데이터 수집/공유? **No**

### 개인 정보
- 이름·이메일·전화번호 등 수집/공유? **Yes** (Google 로그인 시 이메일·이름)
  - → Data Safety 폼과 일치하게 답변

### 공포·테러
- 공포감 유발 콘텐츠? **No**

### 모방 위험
- 사용자가 위험한 행동을 따라할 가능성? **No**

## 예상 등급

위 답변 기준 예상 등급:

| 지역 | 등급 |
|---|---|
| ESRB (북미) | **Everyone** |
| PEGI (유럽) | **PEGI 3** |
| USK (독일) | **USK 0** |
| GRAC (한국) | **전체이용가** |
| IARC Generic | **3+** |

사용자 콘텐츠 공유로 인해 일부 지역에서 등급이 약간 올라갈 수 있으나, 학습 앱 특성상 **3+/Everyone**으로 정착하는 게 일반적.

## 추가 정보 (선택 입력)

콘텐츠 등급 설문 마지막에 "추가 정보" 박스가 있으면:

```
아보카도는 한국어·영어·일본어·중국어 어휘 학습을 위한 개인 학습 도구입니다.
사용자가 직접 단어장을 만들거나 커뮤니티에서 공유된 단어장을 가져올 수 있으며,
모든 콘텐츠는 학습 목적입니다. 관리자가 부적절한 큐레이션을 삭제할 수 있습니다.
```
